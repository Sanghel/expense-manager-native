# Learning Path — Migración React Native

Este folder es tu "RN reference card" del proyecto. Cada doc cubre un bloque específico de conceptos aplicados a una tarea real de la migración.

## Cómo usar este folder

1. Antes de cada tarea (T-X.X) lee el doc correspondiente — son cortos (~10 min).
2. Durante la implementación, vuelve a este folder si algo no te cierra.
3. Al final de cada fase, este `index.md` se actualiza con un resumen de "lo que ahora sabes hacer".
